# 스프린트 #2 Hour 4-7 중간 보고서

## 개요

스프린트 #2 4~7시간 경과. **NPC 대화 읽기**, **침몰 처리**, **보안정책 패턴 분석**이 주요 작업.

## 주요 성과

### 1. NPC 대화 읽기 성공 ✅
- "출항 전 준비 안내" → **바로 출항** 버튼 선택 → 출항 성공
- "물·식량 부족 경고" → **다음** 버튼
- "선원 준비 안내" → **다음** 버튼
- 이전에는 무조건 X/닫기 → 이제 내용 읽고 적절한 버튼 선택

### 2. 출항 성공 + 침몰 발생 💀
- "바로 출항"으로 출항 성공
- 하지만 **목적지 설정 없이** 출항 → speed 0.0 → 정박
- 물/식량 없는 상태로 약탈단에게 당해 **침몰**
- 침몰 팝업에서 **"리스본" 회항 선택** 처리 (Codex 좌표 부정확 → 게임 재시작으로 해결)

### 3. 보안정책 패턴 분석 🔍
로그 분석으로 **정확한 트리거 패턴** 파악:

| 패턴 | 횟수 | 결과 |
|------|------|------|
| NPC 10회 연속 닫기 | 3회 | 게임 강제 종료 |
| 같은 영역 3~4회 반복 탭 | 5회+ | 보안정책 트리거 |
| Codex 부정확 좌표 (75,70), (81,76) | 4회 | 빗나감 → 재시도 → 누적 |
| 접속 3회 반복 | 다수 | 정상 작동 안 하면 반복 |

### 4. 보안정책 회피 강화 🛡️
- **같은 영역(80px) 3회 반복 시 60초 대기** 추가
- **NPC 제한 15→5회**로 축소
- **좌표 검증 >100**으로 상향
- **탭 이력 추적** (최근 20개 저장)

### 5. 클릭 성공 여부 추적 📊
- 탭 전/후 화면 캡처 → 해시 비교
- ✅변화 / ❌무변화 로그 기록
- 모든 탭 이력에 성공 여부 저장

## 발견한 문제들

### 선원 부족
- 출항소에서 "선원 부족" 경고 → 출항 불가
- 출항소 내부에 **"선원 모집"** 버튼 존재 확인
- v5에 선원 모집 최우선 단계 추가

### 자동항로 미설정
- "바로 출항" = 목적지 없는 출항
- 바다에서 정박(speed 0.0) → 결국 침몰
- 출항소에서 **목적지 선택 후 출항** 필요

### Codex 좌표 부정확
- "리스본" 버튼 좌표를 매번 다르게 줌
- 침몰 팝업에서 회항 버튼 위치 부정확
- 탭 성공 여부 추적으로 빗나감 감지 가능
